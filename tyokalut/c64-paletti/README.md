# C64-paletti (Pepto)

Commodore 64:n 16 kiinteää väriä Philip "Pepto" Timmermannin mittaamina. Tämä on yleisimmin käytetty C64-paletti emulaattoreissa ja pikseligrafiikkatyökaluissa.

| Tiedosto | Käyttö |
|---|---|
| `c64-pepto.hex` | Lospec-muoto. Retro Diffusion, PixelLab, Pixelorama ja useimmat verkkotyökalut |
| `c64-pepto.gpl` | GIMP-paletti. Aseprite, LibreSprite, GIMP, Krita |

Värit järjestyksessä C64:n värinumeroiden 0–15 mukaan: musta, valkoinen, punainen, syaani, violetti, vihreä, sininen, keltainen, oranssi, ruskea, vaaleanpunainen, tummanharmaa, harmaa, vaaleanvihreä, vaaleansininen ja vaaleanharmaa.

## Käyttö AI-työnkulussa

1. Generoi kuva AI-työkalulla.
2. Pienennä se kohderesoluutioon (lähin naapuri, ei pehmennystä).
3. Pakota värit tähän palettiin (työkalun "force palette" / "palette converter").
4. Siisti yksittäiset pikselit käsin.

Vaihtoehtoinen, hieman kirkkaampi mittaus on Colodore (2017). Vaihda siihen, jos Pepto näyttää liian sameilta nykynäytöllä.
