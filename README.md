# Pelinkehitys

Kokoelma pelinkehityksen työkaluja, asetuksia ja muistiinpanoja, joita voi käyttää uudelleen muissa projekteissa.

## Rakenne

```
tyokalut/          Yksi kansio per työkalu: arvio, käyttöönotto ja valmiit asetustiedostot
```

## Työkalut

| Työkalu | Mihin | Tyyppi | Hinta | Tila |
|---|---|---|---|---|
| [SpriteCook](tyokalut/spritecook/README.md) | AI-generoidut spritet, animaatiot, tilesetit, UI | Hostattu MCP-palvelin + Claude-plugin | Ilmainen 40 kr/kk, maksulliset 12–100 $/kk | Arvioitu, ei testattu |

## Uuden työkalun lisääminen

1. Luo kansio `tyokalut/<nimi>/`.
2. Kirjoita `README.md`: mitä tekee, käyttöönotto, hinta ja lisenssi, rajoitukset, oma arvio.
3. Lisää mahdolliset valmiit asetustiedostot (esim. `mcp.json`) samaan kansioon.
4. Lisää rivi yllä olevaan taulukkoon.
